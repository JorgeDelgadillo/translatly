# Chrome Web Store Assets

These listing assets are prepared for the Chrome Web Store Developer Dashboard.

- `screenshot-popup.png`: 1280x800 quick-translation listing screenshot.
- `screenshot-translator.png`: 1280x800 full translator listing screenshot.
- `screenshot-selection-bubble.png`: 1280x800 inline bubble listing screenshot.
- `small-promo-tile.png`: 440x280 small promotional tile.
- `marquee-promo-tile.png`: 1400x560 optional marquee promotional tile.
- `small-promo-tile.svg`: editable source for the small promotional tile.
- `marquee-promo-tile.svg`: editable source for the marquee promotional tile.

The screenshots were captured from the Chrome MV3 build. The SVG files are
editable sources; upload the PNG files to the store dashboard.
